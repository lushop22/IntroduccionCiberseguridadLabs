# Laboratorios de Introducción a la Ciberseguridad

Repositorio de los laboratorios y materiales prácticos del curso **Introducción a la Ciberseguridad** de la **Universidad de Ingeniería y Tecnología (UTEC)**.

Las actividades permiten aplicar los conceptos del curso mediante ejercicios progresivos, desde prácticas guiadas hasta retos que los estudiantes deben resolver de forma independiente.

## Objetivos

- Comprender el funcionamiento de sistemas, redes y servicios desde una perspectiva de seguridad.
- Utilizar herramientas para observar, analizar y enumerar entornos de laboratorio.
- Identificar problemas de seguridad y explicar su impacto con evidencias.
- Documentar procedimientos, interpretar resultados y proponer mejoras.

## Contenido

El repositorio se actualizará durante el curso para incorporar laboratorios sobre sistemas operativos, redes, análisis de tráfico, servicios web y otros temas de ciberseguridad.

Entre las actividades preparadas se encuentran la enumeración web y la enumeración de servicios **WordPress, SSH y MySQL**, utilizando herramientas como **Nmap, curl y Gobuster**.

## Organización de los laboratorios

Cada laboratorio tendrá su propia carpeta y podrá incluir:

| Material | Propósito |
| --- | --- |
| README o guía de instalación | Requisitos, preparación y puesta en marcha del entorno. |
| Enunciado y preguntas | Contexto, objetivos y actividades del estudiante. |
| Archivos del laboratorio | Configuraciones, scripts, datos de práctica y recursos necesarios. |
| Material complementario | Diccionarios, ejemplos y documentos de apoyo. |

Las soluciones, procedimientos resueltos y rúbricas del docente se distribuirán por separado cuando la actividad lo requiera. Los retos evaluados no deben incluir sus respuestas en el material entregado al estudiante.

## Cómo utilizar este repositorio

1. Selecciona el laboratorio indicado por el docente.
2. Lee su documentación y comprueba los requisitos antes de comenzar.
3. Prepara el entorno siguiendo las instrucciones de esa actividad.
4. Resuelve las preguntas y conserva las evidencias solicitadas.
5. Documenta tus conclusiones y detén los servicios al finalizar.

Los requisitos varían entre actividades. Algunos laboratorios utilizan máquinas virtuales con Kali Linux, Docker o Docker Compose; otros pueden requerir herramientas diferentes. **Consulta siempre la guía del laboratorio correspondiente.**

## Entregables

Cada enunciado especifica el formato de entrega y los criterios de evaluación. Las respuestas deben relacionar lo observado con evidencias y explicar qué permiten concluir los resultados.

## Entorno de práctica

Realiza las pruebas únicamente sobre los entornos y objetivos autorizados para cada actividad. Los datos y credenciales de demostración se utilizan con fines educativos dentro del laboratorio.
